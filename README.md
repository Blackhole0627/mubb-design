# MUBB Design

Website for MUBB Design Studio: interior design, architecture, and bespoke furniture for residential, hotel, commercial, and yacht projects. A portfolio site — no e-commerce, a contact form ("Solicitar cita") is the main goal.

Industry: interior design / architecture studio (luxury residential, corporate, and hospitality interiors).

## Contents
- `client-references-analysis.md` — analysis of the client's visual references
- `copy-and-content.md` — the client's real page copy, asset inventory, and the decisions made to keep Step 1 moving without blocking on open questions
- `wireframes/index.html` — low-fidelity wireframes for every page, desktop and mobile (open in a browser)
- `tokens.css` — design tokens (black/brown, uppercase Montserrat)
- `cms-schema.sql` — content model: projects, services, finishes, team, press, forms

Step 1 (design and architecture) is complete. Step 2 is implementation.
